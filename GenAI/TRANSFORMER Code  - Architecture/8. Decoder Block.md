```python
class DecoderBlock(nn.Module):
    def __init__(self, self_attention_block : MultiHeadAttention, cross_attention_block: MultiHeadAttention,
                 feed_forward_block: FeedForwardBlock, dropout: float):
        super().__init__()
        self.self_attention_block = self_attention_block
        self.cross_attention_block = cross_attention_block
        self.feed_forward_block = feed_forward_block
        self.residual_blocks = nn.ModuleList([ResidualConnections(dropout for _ in range(3))])
    
    def forward(self, x, encoder_output, src_mask, tgt_mask):
        ''' 
            src_mask - encoder mask, a padding mask
            tgt_mask - decoder mask, masking forward words
        '''
        x = self.residual_blocks[0](x, self.self_attention_block(x, x, x, tgt_mask))
        x = self.residual_blocks[1](x, self.self_attention_block(x, encoder_output, encoder_output, src_mask))
        x = self.residual_blocks[2](x, self.feed_forward_block)
        return x

class Decoder(nn.Module):
    def __init__(self, layers: nn.ModuleList):
        super().__init__()
        self.layers = layers
        self.norm = LayerNormalization()
    
    def forward(self, x, encoder_output, src_mask, tgt_mask):
        for layer in self.layers:
            x = layer(x, encoder_output, src_mask, tgt_mask)
        return self.norm(x)
```

You're now at the point where the **encoder and decoder connect**, and this is where many people get confused.

The biggest misconception is usually:

The answer is **no**. Let's build the entire picture.

### The key idea to remember

The encoder **does not** send Q, K, and V to the decoder.

It sends only its **final contextual representations**:

```text
Encoder Output
(batch, seq_len, d_model)
```

When the decoder performs cross-attention, it computes **new** queries, keys, and values:

- **Query** = `W_q(decoder_hidden_state)`
    
- **Key** = `W_k(encoder_output)`
    
- **Value** = `W_v(encoder_output)`
    

So the encoder output acts as the **raw material** from which the decoder's cross-attention constructs its own keys and values. The original Q/K/V that existed inside the encoder's self-attention layers were temporary—they were used within each encoder block and discarded after the attention computation and output projection (`W_o`).
