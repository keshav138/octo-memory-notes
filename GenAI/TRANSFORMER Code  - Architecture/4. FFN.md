```python
class FeedForwardBlock(nn.Module):
    def __init__(self, d_model: int, d_ff: int, dropout: float):
        super().__init__()
        self.linear_1 = nn.Linear(d_model, d_ff) # W1 and B1, bias term is already set to true, check func. description
        self.dropout = nn.Dropout(dropout)
        self.linear_2 = nn.Linear(d_ff, d_model) # W2 and B2
    
    def forward(self, x):
        '''
            X are input sentences with dimension (batch_size, seq_length, dModel)
            We convert it from  (batch_size, seq_length, dModel) to (batch_size, seq_length, d_ff)  to (batch_size, seq_length, d_ff)
        '''
        return self.linear_2(self.dropout(torch.relu(self.linear_1(x))))

 
```

This is the **Feed Forward Network (FFN)**, one of the two major computations inside every Transformer block (the other being Self-Attention).

A transformer block looks like this:

```text
Input
   │
   ▼
Multi-Head Attention
   │
   ▼
Add & LayerNorm
   │
   ▼
Feed Forward Network  ← This class
   │
   ▼
Add & LayerNorm
   │
Output
```

Notice something important:

- **Attention** lets tokens communicate with each other.
    
- **Feed Forward Network (FFN)** processes **each token independently**.

# Why expand to a larger dimension?

This is one of the most common questions.

Why not simply do

```text
512

↓

512
```

Instead of

```text
512

↓

2048

↓

512
```

Imagine compressing and expanding an image.

A larger hidden space gives the network **more capacity** to learn complex relationships.

Think of it like giving the model a larger "workspace."

```
512 values
      │
      ▼
Expand to 2048 values
      │
      ▼
Perform richer nonlinear transformations
      │
      ▼
Compress back to 512 values
```

This expansion lets the model discover combinations of features that would be difficult to represent directly in the smaller space.

## The complete data flow

If `d_model = 512` and `d_ff = 2048`, then the flow through the feed-forward block is:

```text
Input
(32,20,512)
        │
        ▼
Linear(512 → 2048)
        │
        ▼
(32,20,2048)
        │
        ▼
ReLU
        │
        ▼
(32,20,2048)
        │
        ▼
Dropout
        │
        ▼
(32,20,2048)
        │
        ▼
Linear(2048 → 512)
        │
        ▼
Output
(32,20,512)
```

The crucial point is that **each token is processed independently by the FFN using the same two linear layers**. The FFN never mixes information between tokens—that interaction has already happened in the preceding self-attention layer.
