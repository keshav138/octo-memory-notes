Let's trace the journey of an image through both phases.

The transition from training to testing is all about moving from a strict grading system to a smart filtering system.

### Phase 1: The Training Pipeline (The Grader)

During training, YOLO acts like a student taking a test where we already know the answer key. We pass an image through the network, and it predicts hundreds of bounding boxes. We then use a **Loss Function** (a mathematical grader) to calculate how wrong the network's predictions were, so it can adjust itself.

The loss function penalizes the network in three specific areas:

1. **Coordinate Error:** If the assigned grid cell guesses a box, but the $(x, y, w, h)$ coordinates don't perfectly align with the ground truth box, it gets penalized.
    
2. **Classification Error:** If the cell correctly locates the object but guesses it's a car instead of a dog, it gets penalized.
    
3. **Confidence Error:** This is the most critical part. YOLO penalizes false positives heavily. If a grid cell is empty (contains no object center) but predicts a box with high confidence anyway, the loss function strongly corrects it, teaching it to output $0$ confidence for background patches.
    

_Note:_ Even though a cell predicts multiple bounding boxes, we only penalize the coordinate error for the single box that has the highest IOU with the ground truth. This forces the boxes to "specialize" in different shapes over time.

### Phase 2: The Testing Pipeline (The Filter)

Once training is complete, we feed YOLO a brand new image. Because every grid cell makes multiple predictions, a standard $7 \times 7$ grid predicting 2 boxes per cell will output exactly $98$ bounding boxes all at once. Most of these are useless.

To clean this up, YOLO applies a two-step filtering pipeline:

**Step 1: Confidence Thresholding**

We simply throw away any box where the confidence score is below a certain limit (e.g., discard anything under $0.5$). This eliminates the vast majority of predictions in the background.

**Step 2: Non-Maximum Suppression (NMS)**

Even after thresholding, we might have 5 overlapping boxes tightly clustered around a single dog, all from neighboring cells that thought _they_ were the center. NMS fixes this using the IOU metric we discussed:

- It looks at the remaining boxes for a specific class (like "dog") and picks the one with the highest confidence score.
    
- It then compares that "winner" to all other overlapping "dog" boxes.
    
- If an overlapping box shares too much area with the winner (i.e., its IOU is above a certain threshold, like $0.4$), YOLO assumes it's a duplicate detection of the exact same dog and deletes it.
