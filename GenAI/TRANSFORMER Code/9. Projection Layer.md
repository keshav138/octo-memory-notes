```python
class ProjectionLayer(nn.Module):
    def __init__(self, d_model: int, vocab_size: int):
        super().__init__()
        self.proj = nn.Linear(d_model, vocab_size)
    
    def forward(self, x):
        # (Batch, seq_len, d_model) --> (batch, seq_len, vocab_size)
        return torch.log_softmax(self.proj(x), dim = -1)
```

Perfect timing. This is actually the **last piece of the Transformer**.

Once you understand this layer, you'll understand **how hidden vectors become words**.

## One last subtle but important detail

You might wonder: **how does the projection layer know that one output neuron corresponds to `"Le"` and another to `"chat"`?**

It doesn't "know" initially. When you build the tokenizer, every vocabulary word is assigned a fixed integer ID, for example:

```
3 → Le
4 → chat
5 → boit
...
```

The projection layer always produces `vocab_size` outputs, where **output neuron `i` corresponds to vocabulary ID `i`**. During training, the loss compares the predicted distribution to the correct target ID, and gradient descent adjusts the projection weights so that the correct vocabulary index receives a higher score. Over millions of examples, those weights learn which hidden-state patterns correspond to which words. This is how a vector like `[3.7, -2.1, 0.5, 6.4]` eventually becomes a high score for `"Le"` instead of `"chat"` or `"maison"`.
