A **window function** performs a calculation across a set of table rows that are related to the current row, without collapsing the rows into a single output.

  

Unlike standard `GROUP BY` aggregates—which reduce multiple rows down to one summary row—a window function **preserves every individual row's identity** while appending the calculated result alongside it.

|**id**|**name**|**dept**|**salary**|
|---|---|---|---|
|1|Alice|Sales|5000|

|3|Charlie|HR|4000|
|4|Diana|HR|4500|
|5|Evan|HR|4000|

**Core Use Cases & Examples**

  

- **Running Totals / Cumulative Aggregates:** Calculates an accumulation row-by-row based on a defined order.
    
      
    
    SQL
    
    ```
    SELECT 
        name, dept, salary,
        SUM(salary) OVER (PARTITION BY dept ORDER BY salary) AS running_dept_salary
    FROM employees;
    ```
    
    _Result:_
    
      
    
    |**name**|**dept**|**salary**|**running_dept_salary**|
    |---|---|---|---|
    |Alice|Sales|5000|5000|
    |Bob|Sales|6000|11000|
    |Charlie|HR|4000|4000|
    |Evan|HR|4000|8000|
    |Diana|HR|4500|12500|
    
- **Ranking within Subgroups:** Assigns ranks within a category without filtering out the rest of the records.
    
      
    
    - `ROW_NUMBER()`: Unique sequential integer per row (1, 2, 3...).
        
          
        
    - `RANK()`: Identical values share a rank, skipping subsequent numbers (1, 1, 3...).
        
          
        
    - `DENSE_RANK()`: Identical values share a rank without gaps (1, 1, 2...).
        
          
        
    
    SQL
    
    ```
    SELECT 
        name, dept, salary,
        DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS salary_rank
    FROM employees;
    ```
    
    _Result:_ Bob is 1 and Alice is 2 in Sales; Diana is 1, Charlie & Evan tie for 2 in HR.
    
      
    
- **Row-to-Row Comparisons (Offsets):** Accesses data from preceding or following rows without self-joins.
    
      
    
    - `LAG(col, n)`: Looks backward $n$ rows.
        
          
        
    - `LEAD(col, n)`: Looks ahead $n$ rows.
        
          
        
    
    SQL
    
    ```
    SELECT 
        name, salary,
        LAG(salary, 1) OVER (ORDER BY salary) AS prev_salary,
        salary - LAG(salary, 1) OVER (ORDER BY salary) AS diff_from_prev
    FROM employees;
    ```
    

**Syntax Anatomy**

  

$$\text{FUNCTION}()\ \mathbf{OVER}\ (\mathbf{PARTITION\ BY}\ \text{group\_col}\ \mathbf{ORDER\ BY}\ \text{sort\_col}\ \mathbf{ROWS\ BETWEEN}\ \dots)$$

- **`OVER`**: Signals the window calculation.
    
      
    
- **`PARTITION BY`**: Divides rows into groups/slices (like `GROUP BY`, but keeps rows intact). Optional; if omitted, the whole table is one window.
    
      
    
- **`ORDER BY`**: Sets the sequence for ranking or cumulative frames.
    
      
    
- **`ROWS/RANGE BETWEEN`**: Defines the sliding frame boundaries (e.g., `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`).
